# My agent: RealEstate Scout
One-liner: A conversational agent that helps apartment hunters find, compare, and evaluate rental listings with a catalog of available properties.

Tool coverage:
- Memory: User search preferences (budget, preferred neighborhoods, bedroom/bathroom count, pet policies, must-have amenities) and saved/favorited listings.
- Tools: Search and filter listings by criteria, fetch detailed property specs, save/remove favorites, check tour availability.
- Catalog/UI: Property listings rendered as display cards (price, specs, amenities, photos) and side-by-side comparison tables for shortlisted units.
- Image gen: Virtual staging and decor concepts (e.g., modern minimalist furniture in an unfurnished living room) and neighborhood vibe visuals.
- Sandbox: Affordability calculations, rent-to-income ratios, estimated utility costs, and total move-in cash requirements.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for financial & affordability calculations, live external Maps/Places API for commute and walkability scores, lease agreement document parsing/RAG, Cloud Trace for observability.
